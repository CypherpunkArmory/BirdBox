# Welcome to the BirdBox Android app

The easiest way to run desktop Thunderbird on Android.
Features: 
* Full featured Thunderbird
* Runs locally on your device
* Touch based interface for interacting with Thunderbird

     alt="Get it on Google Play"
     height="80">](https://play.google.com/store/apps/details?id=tech.ula.birdbox)
     
## Have a bug report or a feature request?
You can see our templates by visiting our [issue center](https://github.com/CypherpunkArmory/BirdBox/issues).

## About
This app is not created by the main Thunderbird development team.  Instead it is an adaptation that allows the Linux version to run on Android.
